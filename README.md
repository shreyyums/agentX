# agentX
agentX is an AI-native engine for Poonawalla Fincorp’s 2026 stack. It uses Agentic DQI to cross-verify KYC against offer letters, slashing manual risk checks. Featuring a LangChain orchestrator and Mock LOS/RegIntel APIs, it enables 85% STP and Zero-Touch pre-approvals, turning loans into a high-speed digital journey.
